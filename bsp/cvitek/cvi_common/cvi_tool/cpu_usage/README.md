# RT-Thread 线程性能统计工具 (cvi_perf)

`cvi_perf` 是一个为 RT-Thread 设计的轻量级、低开销的线程性能分析工具。它通过利用 RT-Thread 内核的调度器钩子函数（Scheduler Hook），精确地测量每个线程的运行时间、切换次数，并计算出各个线程以及系统总体的 CPU 使用率。

## 主要功能

*   **线程级CPU占用率统计**：精确计算每个线程的 CPU 时间占比。
*   **系统总CPU占用率**：通过空-闲线程（idle task）的运行时间反算出系统总体的 CPU 负载。
*   **上下文切换计数**：统计每个线程被调度执行的次数。
*   **高精度计时**：在 RISC-V 平台上利用 `rdtime` 指令读取硬件计数器实现高精度计时，也可轻松适配其他平台的高精度时钟源。
*   **低侵入性**：核心数据采集在调度器钩子中完成，对系统性能影响极小。
*   **无浮点运算**：所有百分比计算均通过整数运算完成，避免了因 C 库不支持浮点打印而导致的问题，同时保持了代码的高效和可移植性。
*   **FinSH/MSH 命令集成**：提供简单的命令行接口，方便用户在终端上直接启动和查看性能数据。

## 依赖配置

为了使该工具正常工作，请确保在您的 `rtconfig.h` 或 `menuconfig` 中开启了以下内核选项：

*   `RT_USING_FINSH`：用于支持 MSH 命令行交互。
*   `RT_USING_SCHEDULER_HOOK`：这是本工具实现的核心依赖，必须开启。
*   `BSP_USING_PERF_TOOL`：这是本工具使能宏，必须开启。
*   **内核对象信息**：工具需要遍历系统中的所有线程，这依赖于 `rt_object_get_information()` 函数。请确保您的内核版本支持此功能（在较新的版本中，此功能通常默认开启，无需额外宏定义）。

## 如何使用

1.  **集成到项目**:
    *   将 `perf_stat.c` 文件添加到您的 BSP 或项目工程中，并确保它被包含在 SCons 或其他构建系统的编译列表里。

2.  **启动统计**:
    *   在系统的 FinSH/MSH 终端中，执行以下命令来初始化并启动性能统计：
    ```shell
    msh />perf_init
    ```
    该命令会初始化数据结构，遍历当前所有线程，并挂载调度器钩子函数开始采集数据。

3.  **查看统计结果**:
    *   在运行一段时间后，执行以下命令来显示性能统计报告：
    ```shell
    msh />perf_show_stat
    ```
    该命令会暂停数据采集，打印统计结果，然后自动恢复数据采集。您可以多次执行此命令来观察系统性能的动态变化。

## 输出结果说明

执行 `perf_show_stat` 后，您将看到类似以下的输出：

```
================================================================================
 Total CPU Usage:  12.34%
================================================================================
 Thread Perf Stat (Total 1234567890 ticks)
--------------------------------------------------------------------------------
 Thread Name      | Total Ticks        | Switches Count | CPU Usage
------------------|--------------------|----------------|-----------
 tshell           | 12345678           | 150            |   1.00%
 main             | 98765432           | 2345           |   8.00%
 tidle0           | 1084183743         | 8901           |  87.66%
...
================================================================================
```

*   **Total CPU Usage**: 系统总体的 CPU 负载百分比。
*   **Thread Name**: 线程的名称。
*   **Total Ticks**: 线程自 `perf_init` 以来累计占用的高精度时钟节拍数。
*   **Switches Count**: 线程被调度器切换进来的总次数。
*   **CPU Usage**: 该线程的 CPU 占用时间百分比。

## 平台适配

本工具的核心是高精度计时。`rt_perf_get_ticks()` 函数是计时的唯一接口。

*   **RISC-V 平台**: 已默认使用 `rdtime` 指令读取 `mcycle` 计数器，无需修改。
*   **其他平台 (ARM等)**: 您需要修改 `rt_perf_get_ticks()` 函数，使其返回一个您平台上可用的高精度硬件定时器的计数值（例如 DWT 的 `CYCCNT` 寄存器）。如果平台没有高精度时钟，可以临时使用 `rt_tick_get_us()`，但这会降低统计精度。

```c
static rt_uint64_t rt_perf_get_ticks(void)
{
#if defined(ARCH_RISCV)
    // 对于 RISC-V 系列，可以使用 mcycle 计数器
    rt_uint64_t tick;
    __asm__ __volatile__("rdtime %0" : "=r"(tick));
    return tick;
#else
    // 对于其他平台，请返回一个高精度定时器的计数值
    // 例如 ARM Cortex-M 的 DWT->CYCCNT
    // return DWT->CYCCNT;
    return rt_tick_get_us();
#endif
}
